# 01 · 技术栈说明

> 面向使用者/维护者：本项目用了哪些技术、为什么这么选、各自负责什么。
> 代码在哪、怎么连，见 [`../ARCHITECTURE.md`](../ARCHITECTURE.md)。

## 总览

| 用途 | 选型 | 为什么 |
|---|---|---|
| 桌面外壳 / 原生能力 | Rust + Tauri 2 | 复用系统 WebView2/WebKit，冷启动毫秒级，安装包仅数 MB，内存占用约为 Electron 的 1/5 |
| 原生 Markdown 引擎 | Rust `comrak` | GitHub 官方 cmark-gfm 的 Rust 移植，微秒级解析 GFM 表格、TaskList、GitHub Alerts、Footnotes、Math，并支持 `data-sourcepos` 源码行号映射 |
| 编码识别与无损 I/O | Rust `encoding_rs` + `rfd` | 自动探测 UTF-8 / UTF-8 BOM / UTF-16 / GBK 编码并按原编码保存，杜绝中文乱码与静默丢数据；`rfd` 调用系统原生文件对话框 |
| 前端工作台 | React 18 + TypeScript + Vite | 负责顶栏、同级目录树、阅读/编辑双态切换、浮动大纲（TOC）与主题控制；正文直接挂载 HTML，无虚拟 DOM 重渲染负担 |
| 前端 IPC 封装 | `src/api.ts` + `@tauri-apps/api` | 组件不直接 `invoke`，命令名 / 参数 / 返回类型集中管理，并为 `sh manager.sh web` 提供浏览器预览兜底 |
| 契约测试 | Node.js `node:test` | 不启动应用即可毫秒级校验配置、权限、CSP 与 IPC 三方一致 |
| Rust 测试 / 质量 | `cargo test` · `cargo clippy` · `cargo fmt` | Rust 侧解析、行级任务切换、编码无损往返单元测试与静态检查 |

## 它是怎么跑起来的

1. 双击 `.md` 文件或命令行启动时，Rust 主进程直接从启动参数读取目标路径，调用 `comrak` 一次性生成带 `data-sourcepos` 行号锚点的 HTML、标题大纲（TOC）、字数统计和同目录 `.md` 列表。
2. 前端挂载后通过 `startup_document` 一步拿到首屏数据直接呈现 `.ml-prose` 阅读视图。
3. 在阅读视图下，用户可直接点击勾选 `[ ]` 任务复选框（Rust 按行号原位替换写盘，不改动其余行格式），或**双击任意段落**按源码行号精准跳入编辑模式对应行。
4. 编辑模式提供格式化工具栏与分屏实时预览，`Ctrl+S` 按原文件编码写回磁盘。

## 各组件职责

- `src/`：React UI。负责工作台布局、4 套印刷级阅读主题切换、双击段落行号跳转、分屏编辑器与全文搜索；所有原生调用经 `src/api.ts`。
- `src-tauri/src/markdown.rs`：`comrak` 解析配置、安全 HTML 消毒、代码块头部增强、TOC 提取、文档统计与任务列表行级切换。
- `src-tauri/src/fs_ops.rs`：命令行 `.md` 路径识别、`encoding_rs` 多编码无损解码/编码、同级目录 `.md` 文件扫描、原生文件打开/保存对话框。
- `src-tauri/src/commands.rs`：IPC 命令门面，连接前端与 `markdown.rs` / `fs_ops.rs`。
- `src-tauri/src/lib.rs`：Tauri Builder 与命令注册。
- `tests/contract.test.mjs`：配置与 IPC 契约的机械校验（配合 `sh manager.sh test`）。

## 配置与单一事实源

- **版本号**：只在 `src-tauri/Cargo.toml` 的 `version`；`tauri.conf.json` 省略 `version` 时会回退到它；前端经 `app_info` 命令读取。`package.json` 的 `version` 固定 `0.0.0`，不使用。
- **App 标识**：`src-tauri/tauri.conf.json` 的 `identifier`（`dev.markleaf.app`，发布后不可改）。
- **开发端口**：只在 `build.devUrl`；`vite.config.ts` 从中读取并设 `strictPort`。
- **安全策略**：生产 CSP 在 `app.security.csp`，开发放宽只放 `devCsp`；窗口权限在 `capabilities/`。
- **命令**：统一走 `sh manager.sh <命令>`（`sh manager.sh help` 看全部），速览见 [`02-使用说明.md`](02-使用说明.md) §0。
